# 04 · 角色两两对比结论

用途：记录**已经人工确认过的**差异，避免下次重复判断。相似度脚本只做初筛，结论写在这里。

## 用法

新增角色时：
1. 跑 `tools/check_face_similarity.py` 得到候选相似角色。
2. 对被点名的角色，在这里填一行人工结论。
3. 结论为「撞脸」的，改维度后重跑，直到 <55%。
