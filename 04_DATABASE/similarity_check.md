# 04 · AI 防撞脸 SOP

> 创建新角色 / 重做脸之前，强制执行。

## 步骤

1. **读规则**：`00_PROJECT_RULES/character_rules.md`。
2. **读库**：`04_DATABASE/face_index.csv`（脚本读这份）与 `.xlsx`（人读这份）。
3. **提取新角色 Face DNA**：十二维度，取值来自 `要求.md` 第五、六章词典。
4. **跑脚本**：

```bash
python tools/check_face_similarity.py --name 新角色 --dna "脸型=窄鹅蛋脸;眼型=长杏眼;鼻型=高直鼻;下颌=窄下颌;三庭=中庭略长;眉形=柔剑眉;唇型=上薄下厚"
```

5. **看结果**：

| 相似度 | 处理 |
| --- | --- |
| ≥70% | 撞脸，重做。优先改眼型 → 下颌 → 鼻型 |
| 55–70% | 再拉开至少 2 个维度 |
| <55% | 通过，写入 face_index |

6. **写回**：`face_index.xlsx` + `face_index.csv` 各加一行；冲突结论记入 `character_compare.md`。
7. **锁版**：生成身份标准照定稿后，把 Face DNA 标为 `v001`，此后不可改。

## 权重表（脚本内置）

| 维度 | 权重 |
| --- | --- |
| 脸型 | 3 |
| 眼型 | 3 |
| 鼻型（鼻根+鼻梁+鼻头） | 2 |
| 下颌 | 2 |
| 三庭 / 面中 | 1 |
| 眉形 | 1 |
| 唇型 | 1 |
| 个性标志 | 1 |

## 硬判定

**脸型 + 眼型 + 鼻型 + 下颌 四项全同 → 直接判定撞脸**，不看总分。
