# 能力机制合成规则（能力 ≠ 元素）

> V2 的立论：**能力不要只看元素。** V3 把机制、来源、媒介、接触、结果五轴化。
> 对应 `战斗特效图` 规范：任何能力视觉都必须回答四问，且**必须有材料逻辑**。

## 1. 五轴公式

```
能力 = 机制(Mechanism) × 来源(Source) × 媒介(Medium) × 接触(Contact) → 结果(Result)
```

| 轴 | 取值（摘要） | 说明 |
| --- | --- | --- |
| 机制 | 方向改变/位置改变/空间连接/状态交换/冻结/复制/吞噬/强化/削弱/延迟/加速/折叠/锚定/转移/伪装/记录/回溯/共生/寄生/分解/重构/共振/标记/剥离/回响/嵌套/错位 | 决定「**怎么改变战斗逻辑**」，而非「什么颜色」 |
| 来源 | 血脉/契约/器物/功法/天授/残缺体质/异化/共鸣 | 决定代价与限制从哪来 |
| 媒介 | 气/血/影/声/光/尘/纹/丝/雾/雷 | **材料逻辑的载体**，决定特效质感 |
| 接触 | 接触命中/范围笼罩/视线锁定/地面蔓延/媒介传导 | 决定交战规则 |
| 结果 | 造成位移/改变因果顺序/剥夺行动/交换位置/复制信息/限制变化/吸收结构/改变身体规则/标记目标/制造错误感知 | 决定胜负方式 |

## 2. 特效四问（生成战斗特效图必答）

> **从哪里产生？ → 向哪里运动？ → 接触了什么？ → 接触后发生什么？**

四问缺一，此能力判定为**不合格**，退回重抽。

## 3. 材料逻辑铁律

- 每个能力必须有**真实材料感**：丝→缠/割；尘→掩/蚀；纹→铭刻/封；声→震/引；影→换位/覆盖；血→燃/换。
- **禁止**所有属性都变成「彩色光束 + 粒子 + 法阵」。火/水/雷/土必须有不同**运动方式与接触后果**：
  - 土：位移、承重、锚定、地形改写（不是「土色光柱」）。
  - 火：蔓延、消耗、点燃条件（不是「红光大招」）。
  - 水：渗透、包裹、改变摩擦与温度。
  - 雷：传导路径、瞬间选择（不是「紫色闪电乱炸」）。
- 同一世界里，**两个角色的能力视觉不得同构**（都是「抬手 → 光球 → 爆炸」= 撞机制）。

## 4. 生成时的约束

1. 机制优先：先从 `ability_500.csv` 抽**机制**，再补来源/媒介 → 避免「换色不换招」。
2. 属性必须体现在**媒介运动方式**上，不是颜色上。
3. 每个能力在角色卡里必须写出四问，缺项自动扣「完整度」分。
4. 强机制（吞噬/复制/因果类）必须配**明确代价**（寿命/记忆/感官/身份痕迹）。
