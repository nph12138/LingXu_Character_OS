# Face DNA 组合规则（眼 / 鼻 / 嘴 / 脸型）

> 目的：让 5200 条 Face DNA 是**可读、可信、不趋同**的真实相貌，而不是随机词堆叠。

## 1. 三层结构

每条 Face DNA = **主脸型（70%）+ 辅变化（30%）+ 骨相六项 + 眼四项 + 鼻嘴五项 + 标志**。

| 层 | 字段 | 作用 |
| --- | --- | --- |
| 骨架 | 主脸型 / 辅变化 | 决定轮廓剪影，是全库最严防重复的一层 |
| 结构 | 额头 / 眉骨 / 眼窝 / 颧骨 / 面颊 / 下颌 | 决定「像不像」和年龄感 |
| 五官 | 眼型 / 眼尾 / 眼距 / 虹膜 + 鼻根 / 鼻梁 / 鼻头 + 唇型 / 嘴角 | 决定辨识 |
| 记号 | 特殊标志 | 至少 88% 条目带标志（痣/疤/不对称），用于即时区分 |

## 2. 眼 组合规则

- **眼型 ↔ 眼尾必须同向**：凤系/狐狸系/鹰隼系 → 上挑；下垂眼/疲惫眼 → 下压或下沉；杏眼/圆眼 → 平直或微挑。
- **眼型 ↔ 眼距**：圆长眼/少年圆眼 → 倾向宽眼距；狭长眼/鹰隼眼 → 倾向窄眼距。
- **眼型 ↔ 颧骨/眉骨**：鹰隼眼/狼系眼 需配中高及以上眉骨或外扩颧骨；鹿系眼/下垂眼 配低眉骨、柔和颧骨。
- **虹膜为稀有项**（异色瞳/碎裂虹膜/星点虹膜/环状虹膜）：全库占比 < 8%，只给有机制/身份支撑的角色。
- 禁止：全员「大圆眼 + 高光瞳孔」；禁止不同角色只靠换瞳色区分。

## 3. 鼻 组合规则

- **鼻根 ↔ 眼窝**：深眼窝 → 中高/高鼻根；浅眼窝 → 中/低鼻根。
- **鼻梁 ↔ 骨相**：骨感窄脸/骨感菱形 → 骨感/窄骨鼻梁；圆脸/幼态圆脸 → 柔和/微弧鼻梁。
- **鼻头 ↔ 年龄**：少年 → 小圆/微钝；成年 → 方圆/骨感；40+ → 骨感/下压居多。
- 禁止：所有男性统一「高直鼻」，所有女性统一「小翘鼻」。

## 4. 嘴 组合规则

- **唇型 ↔ 下颌**：宽下颌/方下颌 → 宽嘴或厚唇更协调；窄下颌 → 小嘴或弓形唇。
- **嘴角 ↔ 气质**：上扬=亲和/明亮；下垂=沉郁/疲惫；紧收=克制/危险；单侧上扬=反差/妖异。
- 禁止：全员「上薄下厚 + 嘴角微扬」网红唇。

## 5. 防趋同硬约束

1. **鹅蛋系脸型全库占比 < 25%**（生成器已强制预算）。
2. 同一 (主脸型, 辅变化, 眉骨, 眼型, 鼻梁, 下颌) 组合全库唯一。
3. 任何两个角色的 脸型+眼型+鼻型+下颌 **不得四项全同**（= 硬撞）。
4. 「无标志」条目 < 15%；其余必须带至少一个可绘制记号。

## 6. 写法模板（喂模型时）

```
Face DNA：主脸型 X（辅变化 Y）；
额头…/眉骨…/眼窝…/颧骨…/面颊…/下颌…；
眼：眼型·眼尾·眼距·虹膜；鼻：鼻根/鼻梁/鼻头；唇：唇型·嘴角；
特殊标志：…
```
