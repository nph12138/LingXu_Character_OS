# 防撞脸规则（V3）

> 一句话：**同一世界，不同的人。** 新角色必须与全库任何角色都拉得开。

## 判定阶梯

| 相似度 | 判定 | 动作 |
| --- | --- | --- |
| 四项全同（脸型+眼型+鼻型+下颌） | **硬撞** | 直接重抽，禁止进入 |
| ≥ 70% | 撞脸 | 必须改维度后重跑 |
| 55–70% | 需拉开 | 至少改动两个维度（推荐改眼型 + 下颌线） |
| < 55% | 通过 | 可进入定稿复核 |

## 相似度算法

- 维度权重：脸型 3、眼型 3、鼻型 2、下颌 2（其余维度可扩展）。
- 单维相似度：完全相同 1.0；短语互相包含 0.9（如「长方脸」⊂「长方脸（独立水系冷感骨相）」）；有汉字双字交集 0.7；否则 0。
- 缺失值按 0.5 计（不惩罚信息不全，但也不给高分）。

## 全库硬约束（生成器已强制）

1. 任一 (主脸型, 辅变化, 眉骨, 眼型, 鼻梁, 下颌) 组合**全库唯一**。
2. 鹅蛋系脸型占比 **< 25%**。
3. 「无标志」条目 **< 15%**。

## 与定稿库联动

- 比对源 = `04_DATABASE/face_index.csv`（已定稿角色）。
- 每定稿一个新角色，必须回写该表 → 后续生成自动规避。
- 参考脚本：`tools/check_face_similarity.py`（定稿侧）、`engine/score_character.py --dna`（生成侧）。
