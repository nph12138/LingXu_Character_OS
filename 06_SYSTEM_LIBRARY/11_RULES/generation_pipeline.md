# 生成流程（V3）

> 输入一句话身份描述 → 输出可直接进 Character OS 的角色卡。
> 实现见 `engine/generate_character.py`。

## 输入

```
brief："设计一个25岁土属性镇墟司女性外勤，性格野性但可靠"
```
自动解析：年龄（正则 `\d+岁`）、性别、属性（金木水火土电雷）、阵营、气质词、原型。

## 七步

| 步 | 动作 | 数据源 |
| --- | --- | --- |
| 1 | **选原型** Archetype | `10_ARCHETYPE`；按 气质tone↔原型 与 阵营↔原型 打分，年龄不符的原型（如少年兵≥22岁）排除 |
| 2 | **抽 Face DNA** | `01_FACE_DNA/face_dna_5000.csv` |
| 3 | **撞脸检查** | 对 `04_DATABASE/face_index.csv`；四项全同=硬撞 → **重抽**；≥55% 也重抽 |
| 4 | **气质 / 身体 / 发型** | `02_PERSONALITY`、`03_BODY`（按性别过滤）、`04_HAIR` |
| 5 | **服装 / 材质** | `05_COSTUME`（优先匹配阵营）、`06_MATERIAL` |
| 6 | **能力 / 武器 / 领域** | `07_ABILITY`（机制优先）、`09_WEAPON`、`08_DOMAIN` |
| 7 | **评分 + 导出** | `score_character`；写 `export/<姓名>_v3auto_<日期>.md|json` |

## 关键约束

- **重抽上限 400 次**；仍不达标则返回全库相似度最低的那一版（并标注）。
- 气质词若用户指定，作为「第一眼/第二眼/第三眼」，视觉化行必须与其一致（不可串词）。
- 性别影响身体模板；阵营影响服装剪影；属性影响能力媒介的**运动方式**（非颜色）。

## 输出

- `<姓名>_v3auto_<日期>.md`：角色卡（基础信息 / 气质 / Face DNA / 身体发型 / 服装 / 能力 / 武器 / 领域 / 评分 / 撞脸Top5）。
- `<姓名>_v3auto_<日期>.json`：结构化数据，供后续自动化。

## 落地到 Character OS

1. 人工复核（脸/身体/能力锚点是否可信、是否撞现有世界观）。
2. 锁定 Face DNA → 写 `01_CHARACTERS/<角色>/character.md|face_dna.md|identity_anchor.md`。
3. `04_DATABASE/face_index` 加一行 → 提交。
