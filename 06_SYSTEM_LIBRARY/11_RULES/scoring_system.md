# 自动评分系统

> 目的：让「生成出来的角色」有一个可比较的质量分，并拦住同质化。
> 实现：`engine/lingxu_lib.py::score_character()`，CLI 见 `engine/score_character.py`。

## 总分公式

```
总分 = 新颖度 × 0.35 + 一致性 × 0.25 + 辨识度 × 0.20 + 完整度 × 0.20
```

| 维度 | 权重 | 算法 | 满分条件 |
| --- | --- | --- | --- |
| **新颖度** | 35% | `100 − 与全库最高相似度`；硬撞直接 0 | 与现有角色相似度越低越高 |
| **一致性** | 25% | 原型↔气质 tone 命中 60% + 原型↔阵营命中 40% | 原型、气质、阵营互相说得通 |
| **辨识度** | 20% | 基础 40；有标志 +25；非鹅蛋主脸 +20；武器机制&能力机制齐 +15 | 有独立记号 + 不撞主流脸 |
| **完整度** | 20% | 年龄/性别/阵营/属性/原型 填齐比例 | 关键字段不缺 |

## 等级

| 等级 | 分数 | 处理 |
| --- | --- | --- |
| **S** | ≥ 88 | 直接进定稿复核 |
| **A** | 78–87 | 通过，微调即可 |
| **B** | 68–77 | 需人工拉开 1–2 个维度 |
| **C** | 55–67 | 同质化偏高，重抽 |
| **D** | < 55 | 撞脸/信息缺失，作废重抽 |

## 气质 tone 表（一致性用）

`野性/暴烈/张扬/强健/躁动/放纵 → wild`；`可靠/坚毅/沉稳/从容/克己 → steadfast`；
`清冷/孤傲/疏离/冷酷/沉静/隐忍 → cold`；`温柔/柔软/温润/亲和/悲悯/温雅 → warm`；
`危险/狠戾/妖异/凌厉/疯狂 → danger`；`聪慧/神秘/通透/警觉/神性 → clever`。

原型 → 允许 tone：如「狂战士 = wild+danger」「医者 = warm」「隐修 = cold+clever」。

```bash
python engine/score_character.py --json export/XX_v3auto_2026-09-10.json   # 重算总分
python engine/score_character.py --dna "脸型=长方脸;眼型=狭长眼;鼻型=骨感鼻梁;下颌=宽下颌"
```
