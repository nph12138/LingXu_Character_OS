# 00 · 防撞脸规则与 Face DNA 制度

## Face DNA 十二维度（每个角色必须填满）

1. 脸型（可 70% 主型 + 30% 副型）
2. 三庭比例 / 面中长度
3. 眉骨
4. 眉形
5. 眼型
6. 眼距 / 眼位
7. 鼻根
8. 鼻梁
9. 鼻头 / 鼻翼
10. 唇型 / 嘴宽
11. 下颌
12. 下巴 + 至少一个个性标志（痣、疤、不对称）

> 维度词典（A–AB 组）见旧库 `要求.md` 第五、六章，设计时从词典取值，不要临场造词。

## 设计顺序

**先保证差异 → 再保证协调 → 再保证美感。**

- 用受角色性格控制的半随机组合：冷静 ≠ 一定细长眼，强势 ≠ 一定剑眉，男性 ≠ 一定高鼻深眼窝。
- 相邻主要角色至少在 **脸型 / 眼型 / 鼻型 / 下颌** 中的三项明显不同。
- 不允许只靠发色、瞳色、衣服颜色区分两个人。
- 连续出现「窄鹅蛋脸 + 高鼻梁 + 大杏眼 + 尖下巴」= 设计失败。

## 撞脸判定（硬规则）

| 条件 | 判定 |
| --- | --- |
| 脸型 + 眼型 + 鼻型 + 下颌 四项全同 | **直接判定撞脸，必须重做** |
| 相似度 ≥ 70% | 必须修改，优先改眼型 / 下颌 / 鼻型 |
| 相似度 55–70% | 至少再拉开 2 个维度 |
| 相似度 < 55% | 通过 |

相似度由 `tools/check_face_similarity.py` 计算（见 `04_DATABASE/similarity_check.md`）。

## 身份锁定

角色完成「图1 身份标准照」后锁定：

- **Face Identity**（脸、骨相、五官比例、年龄）—— 永久不可改
- **Hair Identity**（发色、分缝、轮廓、长度、关键发饰）—— 换造型需记入生成日志
- **Body Identity**（身高、头身比、肩腰胯、肌肉类型）—— 不可改
- **Costume Identity**（主色、剪影、关键结构、最重要配饰）—— 可换，但换了脸不许跟着换

## 恶灵专用

- 不能只是「正常人换个红眼睛」，至少 2–3 个结构级非人特征
  （尸感/风化皮肤、异常瞳孔、骨骼异常、寄生结构、裂纹、纸化、木化、机械化、半透明区域、关节异常、固定表情、镜面错位、虫纹、非人肢体比例等）。
- 恐怖来自**结构 + 材质 + 动作**，仍必须保持 72/28 CG 风格。
