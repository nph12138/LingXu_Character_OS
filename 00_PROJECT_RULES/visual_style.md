# 00 · 统一视觉风格（最高优先级）

> 所有角色资产、重绘、批量生图、视频参考共用这一套风格记忆。
> 细化词典见旧库 `要求.md` 第一、二章；本文是可执行摘要。

## 核心比例

- **写实度 70–75%，动漫度 25–30%**（默认取 72 / 28）
- 风格名：半写实国风 3D 动画、影视级东方幻想游戏 CG

## 渲染要求

| 项 | 要求 | 禁止 |
| --- | --- | --- |
| 皮肤 | 细微毛孔、自然起伏、克制粗糙度、轻微血色变化 | 塑料皮、蜡像皮、过度磨皮、真人摄影级瑕疵 |
| 眼睛 | 可略美型，但虹膜/眼白/眼裂/眼球比例符合可信成年结构 | 大虹膜娃娃眼、幼态圆眼模板 |
| 骨相 | 鼻梁、颧骨、下颌、眉骨、眼窝、面中长度真实成立 | 骨相缺失、脸型趋同 |
| 光影 | 电影级自然光、真实软影、环境光、克制体积光 | 平涂、赛璐璐阴影、二维描边、粉饼式明暗 |
| 头发 | 高精度束状发丝：发根、分缝、厚度、重量、碎发、真实高光 | 假发片感、二维线稿发丝 |
| 材质 | PBR：布料/皮革/金属/玉石/骨饰厚度与磨损分明 | 材质糊成一团 |

## 判断口径

- <70% 写实：眼大、皮净、骨相不足、幼态或二维美型感过强 → 不合格。
- >75% 写实：接近真人写真/摄影 → 破坏统一 CG 建模感 → 不合格。
- 合格甜点区：真实成年东亚骨相 + PBR 材质成立，同时保留 25–30% 国漫美型。

## 同脸铁律（资产板专用）

1. **唯一母版脸**：一个角色的所有视图共享同一个三维头模与同一套五官参数，禁止逐视图重新设计。
2. **先锁脸再复制**：先定「图1 身份标准照」的胸像母版脸 → 复制到正面全身 → 再旋转得到侧面/背面。
3. **禁止漂移**：特写成熟而全身幼态、全身眼睛变大、脸变窄、下巴变尖、鼻梁变短、侧面换人 —— 任一项出现即整板重做。
4. 老人、儿童、美女、男性、恶灵必须处于**同一个 CG 渲染域**，不能某些像真人、某些像动画。

## 参考图规则

- 默认只继承参考图的**渲染域**（写实度、CG 质量、镜头、构图、姿态、光影、材质方向）。
- 默认**不继承**脸型、五官、身份、完整发型与服装 —— 除非用户明确说「就这张脸 / 就是这个角色」。
- 优先级：**文字设定 > 已锁定身份图 > 当前参考图**。
- 该角色已确认的身份标准照 = 之后所有图的最高身份锚点。
