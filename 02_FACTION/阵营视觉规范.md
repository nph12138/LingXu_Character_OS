# 阵营视觉规范

> 目标：一眼分阵营，但不牺牲角色辨识度。阵营统一的是**配色 / 材质 / 纹章 / 剪影逻辑**，不是脸。

## 规则

1. 阵营只约束到 Costume Identity，不进入 Face Identity。
2. 同阵营角色至少在脸型 / 眼型 / 鼻型 / 下颌中三项不同。
3. 属性（金木水火土电）决定特效材料，不决定脸。
