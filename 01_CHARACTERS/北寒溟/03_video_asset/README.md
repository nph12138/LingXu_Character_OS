# 视频角色资产图

目录用途：图生视频一致性参考：大身份胸像 + 正/侧/背 3 个全身，背景简单

命名：`<拼音ID>_videoasset_v00n.png`，例：`xinglan_videoasset_v001.png`

- 拼音 ID：角色拼音，全小写无空格，如 xinglan / beihanming
- 版本：v001 初版 / v002 修正 / v003 定稿；换装加后缀，如 `_v004_dress02`
- 预览图（≤512px）同名加 `_preview`，随 Git；4K 原件走 Git LFS
- 废案移入 `05_GENERATION_LOG/rejected_designs/` 并写明失败原因

规范全文见 `00_PROJECT_RULES/image_standard.md`。
